Кочарян Элина Самвеловна БПИ-244
---
-sender.c (передатчик): запрашивает PID приёмника и одно целое число. Побитово шлёт SIGUSR1 для «0» и SIGUSR2 для «1»; после каждого бита ждёт ACK (тот же сигнал) с таймаутом, после посылает SIGINT. При отсутствии ACK выводит ошибку и завершает работу
-receiver.c (приёмник): запрашивает PID передатчика; на каждый полученный SIGUSR 1 или 2 накапливает бит и сразу отправляет ACK тем же сигналом; по SIGINT выводит итоговое число в десятичном виде и завершает работу
---
Для запуска:
gcc -std=c11 -Wall -Wextra receiver.c -o receiver
gcc -std=c11 -Wall -Wextra sender.c -o sender
./receiver   
./sender
